# ShibaPlan 浏览器助手 (Manifest V3)

与 ShibaPlan 同源设计语言（支持 Paper / Light / Dark 主题与 ShibaPlan 图标）的专用浏览器扩展，自动在后台采集浏览器内需要登录态的页面数据，支持独立代码编辑工作台，并支持右键快速推送文本/时间倒计时到 ShibaPlan 本地 Push 服务（`http://127.0.0.1:18421`）。

## 核心能力
1. **独立设置与代码编辑工作台（语法高亮）**：
   - 点击弹窗右上角「设置与代码」或「+ 编写 JS 脚本」即可打开独立标签页工作台。
   - 内置行号与 JS/JSON 语法高亮编辑器（支持 `Tab` 缩进、`Ctrl+S` 保存、一键插入模板与 JSON 格式化）。
   - 支持 **自定义 JS 脚本 (`custom_js`)**、**小红书内置脚本 (`xiaohongshu`)**、**CSS 选择器监控 (`selector`)** 与 **纯后台 API/JSON 静默抓取 (`fetch`)**，支持随时启用、停用与删除脚本。
2. **全自动后台定时采集（无需逐个手动打开网页）**：
   - **纯后台 API (`fetch`)**：直接在 Service Worker 后台携带浏览器 Cookie 请求接口，完全不打开标签页。
   - **DOM / 自定义 JS 脚本**：按间隔（默认每 60 分钟，或每天固定时间 `HH:mm`）与浏览器启动后在后台静默打开标签页（`active: false`）执行脚本 -> 推送到 ShibaPlan -> 自动关闭临时页签。
3. **右键快捷推送到 ShibaPlan**：
   - **推送选中内容到 ShibaPlan**（自动识别日期时间并附带来源链接）。
   - **选择时间添加倒计时推送...**（剩余 `<= 7 天` 或已到期自动标红，后台定时刷新）。
   - **点选网页元素添加监控脚本** / **推送当前网页到 ShibaPlan** / **立即同步当前页匹配脚本**。

## 安装与自定义脚本提示
1. 在 ShibaPlan「信息」仪表盘开启 **外部推送服务**（建议开启“自动创建卡片”）。
2. 打开 `edge://extensions/` 或 `chrome://extensions/`，开启 **开发者模式** -> **加载解压缩的扩展** -> 选择 `extensions/shibaplan-companion`。
3. 如需运行「自定义 JS 脚本 (`custom_js`)」，请在浏览器扩展详情页中开启 **允许用户脚本** 开关。

## 隐私与 Git 隔离
- 扩展源码仅包含通用代码，不包含任何账号、Cookie 或个人 URL。
- 你的所有脚本代码、规则、Push Token、时间倒计时与历史数据均保存在浏览器 `chrome.storage.local` 中，不会写入 Git 仓库。
