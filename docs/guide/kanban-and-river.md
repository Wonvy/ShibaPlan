# 看板、自由画布与灵感流

看板（Board）与底部的灵感流（Idea River）构成了 ShibaPlan 的日常推进核心：**先无负担捕获碎片想法，再按节奏拖入看板执行**。

---

## 自定义看板（Kanban Board）

### 1. 灵活列管理
- **自由新建与配色**：按你真实的工作阶段创建列（例如 `待整理`、`视觉设计`、`前端开发`、`硬件评测`），支持 6 种柔和语义色标。
- **拖拽排序与调宽**：按住列头横向拖动调整列顺序（带精准插入指示线）；拖动列右边缘自由调整单列宽度，或在列头右键选择「恢复默认宽度」。
- **双击折叠列**：双击任意列标题可将该列折叠为紧凑的统计卡片，释放横向视野。
- **按列定制显示项**：右键点击列头，可单独开关该列卡片的**耗时统计、关联日期、备注摘要、配图预览**。

### 2. 自由画布模式（Free Canvas）
除传统横向流式列布局外，看板支持切换至**自由点阵画布**：
- **平移画布**：按住 `Space + 鼠标左键拖拽`（或鼠标中键拖拽）。
- **自由缩放**：支持缩放画布比例、一键**自动整理排列**与**适配屏幕视野**。
- **智能对齐辅助线**：移动看板列时自动吸附并显示对齐参考线。

### 3. 本地文件与文件夹快捷卡片
在桌面端运行 ShibaPlan 时，可直接从系统资源管理器（Explorer / Finder）将**一个或多个文件、项目文件夹**拖入任意看板列：
- **文件夹卡片**：可在卡片内直接点击「展开查看文件」实时预览目录内子文件，点击文件即可调用系统默认程序打开，无需反复切回资源管理器翻找目录。
- **剪贴板悬停秒贴**：鼠标悬停在目标看板列上按 `Ctrl + V`，可直接把剪贴板中的**截图**保存至本地 `assets/` 并创建附图任务卡，或将多行文本快速拆分为卡片。

### 4. 任务专注计时与历史撤销
- 每张卡片支持设置预估工作量（`S: 30m` / `M: 90m` / `L: 180m` 或自定义分钟数）、重要星标与紧急度色条。
- 点击卡片上的「开始专注」自动累计实际投入时长并写入 `focusLogs`。
- 全局支持 `Ctrl + Z` / `Ctrl + Shift + Z` **最多 30 步撤销与重做**。

## 灵感流与全局闪念（Idea River & Quick Capture）

### 1. 底部漂流灵感坞
位于主窗口底部的灵感流默认以多轨道缓流方式展示近期碎片想法，避免传统待办列表带来的压迫感：
- **双模式切换**：支持「河流漂流模式」（可调慢/中/快流速或暂停）与「分页列表模式」（鼠标滚轮快速翻页）。
- **拖拽交互**：
  - 直接将灵感胶囊**拖到上方看板列**或**时间日历某一天**，自动转化为正式任务；
  - 拖拽时按住 `Alt` 键为**复制转入**（保留原灵感不移入回收站）；
  - 双击「灵感流」标题栏可一键折叠/展开底部面板，拖动上边框可自由调节面板高度。
- **回收站保护**：已转入看板或手动删除的灵感会暂存在**灵感回收站**中，随时可一键恢复或通过 `Ctrl + K` 搜索找回。

### 2. 全局快捷键闪念窗口
无论当前正在全屏使用 Photoshop、CAD、VS Code 还是浏览器：
- 按下 **`Alt + Space`**（若被系统输入法或启动器占用，自动回退注册 **`Ctrl + Shift + Space`**）即可在屏幕中央唤起轻量无边框闪念窗。
- 支持直接输入文字、`Ctrl + V` 粘贴剪贴板截图、拖入本地文件，按 `Enter`（或 `Ctrl + Enter`）毫秒级落盘并自动隐藏窗口。

### 3. 一键导出 AI 结构化提示词
点击任意灵感打开详情弹窗：
- **复制给 AI**：自动将灵感正文、标签、时间与上下文组装为清晰的 Markdown Prompt 复制到剪贴板；
- **导出 `.md`**：一键保存至数据目录下的 `ideas/` 文件夹，方便配合外部编辑器或 AI 编程工具直接读取。
