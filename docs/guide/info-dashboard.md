# 信息仪表盘与自动化

「信息（Info）」视图是 ShibaPlan 内置的**可编程自动化监控与信息聚合工作台**。无需编写前端界面，只需一段几行的脚本、一条系统命令、一个 HTTP 接口或一次外部 Webhook 推送，就能在桌面上生成实时刷新的结构化卡片。

---

## 1. 多画布与布局模式

- **多看板标签页**：可按主题建立多个独立画布（如 `本机与服务状态`、`项目构建监控`、`行业资讯聚合`）。
- **三种画布布局**：
  - **自由布局（Free）**：像素级拖拽定位与自由缩放宽高，支持网格线显示、自动吸附（Snap）与防重叠开关；
  - **栅格布局（Grid）**：按 12 列网格规整对齐；
  - **紧凑流式（Compact）**：自动紧密排列卡片。
- **画布锁定**：排好版面后可一键开启「锁定画布」，防止日常点击操作时误拖卡片位置。

---

## 2. 六种卡片数据源类型

新建或编辑卡片时，可按场景选择以下 6 种数据源（`source.kind`）：

| 类型 | 标识 | 适用场景与运行机制 |
| :--- | :--- | :--- |
| **本地脚本** | `script` | 直接在内置代码编辑器编写或选择本地脚本，原生支持 **Python / PowerShell / Node.js / Batch / Bash**（Windows 下自动处理 UTF-8 编码与 `.ps1` BOM，静默无黑框运行） |
| **系统命令** | `command` | 直接执行单行 CLI 命令（如 `git status -s`、`docker ps`、`nvidia-smi`），自动捕获 `stdout` 渲染 |
| **HTTP 请求** | `http` | 定时请求任意 REST API（支持 `GET/POST/PUT/PATCH/DELETE`、自定义请求头与 **JSONPath** 字段提取，如 `$.data.items`） |
| **外部推送** | `push` | **零轮询开销**：由外部脚本、服务器定时任务或 CI 流水线主动 `POST` 到本机 `18421` 端口实时更新卡片（支持过期置灰提醒 `staleAfterMinutes`） |
| **分组容器** | `container` | 在画布中创建视觉分组框，收纳多张子卡片 |
| **原子控件** | `control` | 轻量开关按钮或图标快捷动作，点击即可执行脚本、命令、打开网页或打开本地路径 |

---

## 3. 调度策略与运行保障

每张拉取型卡片（`script` / `command` / `http`）均支持三种调度模式：
1. **手动触发（Manual）**：仅在点击卡片右上角刷新按钮或全局「刷新全部信息卡片」时运行。
2. **固定间隔（Interval）**：按设定秒数循环采集，支持勾选「启动软件时立即运行一次（Run on Startup）」与单卡一键暂停。
3. **Cron 表达式（Cron）**：按标准 5 段 Cron 计划定时触发（如 `*/15 * * * *` 每 15 分钟、`0 9 * * 1-5` 工作日早 9 点）。

**稳定性保障**：
- 单卡执行超时保护（默认 `30s`，可调范围 `2s ~ 300s`），超时或手动取消时在 Windows 下自动通过进程树清理子进程，绝不残留僵尸进程；
- 单次输出流上限 `1MB`，结果自动缓存至 `info-cache/results.json`，下次打开软件即刻呈现上次快照。

---

## 4. 七种可视化显示版式

卡片支持在外观设置中指定 **自动识别（`auto`）** 或强制转换版式：
- **自动识别**：若输出符合 [`shibaplan-info/v1` 标准协议](/api/info-protocol)，支持在同一张卡片内混排多种组件；若为普通 JSON 或纯文本则智能降级排版。
- **指定版式**：可一键切换为 **KPI 指标卡（`metrics`）**、**列表视图（`list`）**、**键值面板（`kv`，点击值自动复制）**、**数据表格（`table`）**、**Markdown 富文本（`markdown`）** 或 **等宽终端纯文本（`text`）**。
